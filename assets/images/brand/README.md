# Closetimo 브랜드 이미지

이 디렉터리에는 출시용 원본 브랜드 이미지를 보관한다.

- `closetimo-app-icon-1024.png`: App Store 및 Google Play 등록용 원본 앱 아이콘
- `closetimo-play-feature-graphic-1024x500.png`: Google Play 피처 그래픽
- `closetimo-launch-logo.png`: 런치 화면용 원본 로고

플랫폼별 앱 아이콘과 런치 이미지는 이 원본에서 내보내 `ios/Runner/Assets.xcassets/`,
`android/app/src/main/res/`에 반영한다.
