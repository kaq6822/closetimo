## 리뷰 지적 수정 (2026-10-07)

- 간격 검사에서 누락되던 이름자 EdgeInsets·다중 행 SizedBox를 보완하고 회귀 테스트 3개를 추가했다. 누락된 숫자 리터럴 32건과 숫자가 섞인 토큰 계산식 33건을 동일 치수의 토큰으로 정리했다.
- SC-004 측정에서 복제 필터 로직을 제거했다. 실제 UI 조건 변경부터 production repository 결과가 그리드 레이아웃에 반영될 때까지 측정하고, 5회 표본의 최댓값으로 판정한다.
- 전체 흐름에 착용 6회·dirty 전환·세탁 초기화를 추가했다. `tool/verify_full_flow.sh`는 앱 설치를 유지한 채 프로세스만 종료하고, 별도 실행으로 의류·설정·마지막 탭·이벤트 복원을 확인한다. Flutter drive의 기본 종료는 앱을 삭제하므로 두 실행 모두 `--keep-app-running`을 사용한다.
