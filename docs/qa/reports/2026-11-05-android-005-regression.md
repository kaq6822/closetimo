## 3. 탐색 QA 상세

### 3.1 단일 등록 + 사진 분석
- 운동화 사진 → 배경 제거(contain), 종류 **신발** 자동 선택, 색상 검정·빨강·버건디, 이름 힌트 "비워 두면 '검정 신발'(으)로 저장돼요" → 이름 비워 저장 → 홈 "오늘 입은 옷"에 "검정 신발"(`qa_1105_03`~`05`).

### 3.2 여러 장 등록 → 정리하기

- 청바지: **하의/청바지** 자동, 이름 "데님 청바지"(`qa_1105_07`). 마지막 카드에서 "저장하고 끝내기"로 바뀜.
- 티셔츠(착용 사진): **하의/청바지**, 이름 "빨강 청바지"로 제안(사진의 청바지를 잡음, T019 A23 측정과 같은 한계)(`qa_1105_08`). "나중에" → 홈 복귀.

### 4.1 D-01 수정·재확인

사진의 종류·세부 종류 제안은 `lib/features/add_item/batch_suggestions.dart`(메모리)에 두고, 정리하기 카드가 미분류 옷이면

- 실기기 재확인(release): 청바지·티셔츠 2장 → 카드 1/2 "데님 청바지"(하의/청바지 미리 선택, 안내 표시) → 둘 다 "나중에" →
