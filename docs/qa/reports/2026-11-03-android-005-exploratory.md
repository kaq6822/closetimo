## 3. 상세 결과

### 3.1 단일 등록 + 사진 분석 (US1·US8)
- 등록 화면에 "여러 장 한 번에 등록" 진입점 노출. 이름·종류·색상 모두 선택(명칭 힌트 "이름 또는 사진 중 하나만 있어도 돼요") — `qa_005_02`.
- 앨범에서 1장 선택 → "사진 분석 중…" 배지(`qa_005_03`) → 약 3~4초 후 배경이 제거된 사진(contain + 여백), 색상 "파랑" 자동 선택·"사진에서 골랐어요. 맞지 않으면 바꿔 주세요" 문구, 명칭 힌트 "비워 두면 '파랑 옷'(으)로 저장돼요"(`qa_005_04`, `05`).
- 사진 시트의 "원본 사진 사용" → 원본(cover)으로 전환(`qa_005_06`, `07`). 종류 "상의" 선택 후 이름을 비워 저장 → 이름 "파랑 상의"로 저장, 홈 "오늘 입은 옷"에 타일 노출(`qa_005_09`).
- 설정 "사진 배경 자동 제거" 끄고 사진 선택 → 배경 제거 없이 원본, 색상 제안은 유지(`qa_005_37`).
- 합성 이미지(티셔츠)에서는 ML Kit 라벨이 매핑되지 않아 종류·세부 종류·소재 제안이 나오지 않았다(O-1). 색상 제안만 동작.
- 카메라 촬영 진입 후 back 취소, 앨범 선택기 back 취소 → 등록 화면 복귀, 크래시 없음. dirty 상태 back → "작성을 그만두시겠어요?" → 나가기(`qa_005_38`).
- 앱 매니페스트에 `CAMERA` 권한이 없고 시스템 카메라 앱 인텐트를 쓰므로 권한 거부 시나리오는 해당 없음(`pm revoke`가 "has not requested permission"으로 거부됨).

### 3.2 여러 장 등록 → 정리하기 (US2·US3)
- 선택기에서 4장 선택 → 완료 → 약 8초 후 `/sort-items` "정리하기 1 / 4" 진입(`qa_005_12`). 항목 이름은 색 기반 임시명("파랑 옷" 등).
- "저장하고 다음"(상의) → 2/4, "나중에" → 3/4(검정 옷, 색 검정 자동 선택, `qa_005_15`), "저장하고 다음"(아우터) → 4/4에서 버튼이 "저장하고 끝내기"로 바뀜(`qa_005_16`), 하의 저장 → 홈 복귀.
- 홈에 "정리 대기 1벌 — 종류·색상·계절을 탭으로 골라 정리해요" 카드(`qa_005_19`). 카드 탭 → "정리하기 1 / 1"(베이지 옷), back → 홈 복귀.
- `force-stop` 후 재실행해도 정리 대기 1벌 유지(콜드 스타트 3.7초, debug).
- 옷장에서 정리 대기 중인 옷은 "미분류" 칩 항목으로 노출, 전체 5벌 일치.
- 세로 고정(`screenOrientation=portrait`)이라 회전 불가가 의도 동작. 가로 전환 설정에도 레이아웃 불변, 크래시 없음.

### 3.3 홈·옷장·세탁·설정
- 홈 "오늘 입은 옷": 타일 선택(checkable) → "오늘 1벌 기록"·"날짜·메모" 버튼 노출 → 기록 시 토스트 "오늘의 착용을 1벌 기록했어요 / 실행 취소"(`qa_005_10`, `11`). 토스트가 하단에서 세탁 바구니 카드를 덮는다(O-4).
- 옷장: 검색창 + "상세 필터" 버튼, 종류 칩(미분류 포함), "입을 수 있음"·"가을 옷" 칩, 정렬(`qa_005_20`).
- 상세 필터 시트: 색상(개수 표기)·계절·용도, "선택 해제"/"N벌 보기". 파랑 선택 → "2벌 보기" → 결과 2벌, 필터 버튼에 배지 "1"·"결과 2벌"·"조건 초기화"(`qa_005_22`~`24`).
- "가을 옷" 칩: 계절 미지정은 포함. 빨강 하의를 겨울로 수정한 뒤 가을 옷 칩 → 결과 4벌(빨강 하의 제외), 안내문 "계절에 가을이 있거나 계절을 정하지 않은 옷이에요."(`qa_005_25`, `30`). 수정 화면은 변경이 없을 때 "저장"·"수정 완료" 비활성, 변경 시 활성(14일 UI-11 지적과 달라짐).
- 세탁: 바구니 3점 → 그룹 헤더 "흰옷·밝은색 1"·"어두운색·색깔 옷 2"와 "그룹 선택" 버튼(`qa_005_31`). 그룹 선택 → 해당 2점 checked, 완료 버튼 활성(`qa_005_32`). 완료 → "세탁 대기 1점"(`qa_005_33`).
- 설정(`qa_005_34`, `35`): "사진 분석" 섹션에 "사진은 이 기기 안에서만 분석하고 밖으로 보내지 않아요. 다만 Google ML Kit가 기능 진단 정보(기기 모델·성능 지표 등)를 Google에 보낼 수 있어요. …" 문구, "사진 색상 추천 — 항상 켜짐", "사진 배경 자동 제거" 토글(기본 켜짐, 끄기 동작 확인). "기기 내 AI로 자세히 분석"(Gemini Nano) 토글은 이 기기(A23, AICore 미지원)에서 노출되지 않음 — spec US8-3의 미지원 기기 동작과 일치. 알림 문구는 "알림 발송은 준비 중이에요"로 정리됨(F-06 문구 개선 확인), "개인정보 처리방침"·"데이터 백업"·"백업에서 복원" 탭 가능.

|---|---|---|---|
| O-1 | 관찰 | 합성 티셔츠·바지·코트 이미지에서는 종류·세부 종류·소재 제안이 나오지 않고 색상만 제안됨. 실제 의류 사진에서의 라벨 정확도는 이번에 검증하지 못함(합성 이미지 한계). T021 사용성 평가 또는 실사진 재검증 필요 | `qa_005_04`, `05` |

| O-4 | 관찰 (P3 후보) | 홈 "오늘 입은 옷" 기록 토스트가 화면 하단 세탁 바구니 카드 위에 뜬다(상단 배치 대상 아님). 2초 후 사라지고 IgnorePointer라 조작은 막지 않음. 직전 N-02와 같은 계열 | `qa_005_11` |
